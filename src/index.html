Expected = ค่าที่ไฟล์ Excel ต้นทางคำนวณไว้จริง · เทียบทุกฟิลด์ผลลัพธ์ (tolerance ±0.005)
อ่านตามลำดับการคำนวณจริง 0 → 7 · อ้างอิงเฉพาะชื่อช่องในหน้านี้ — ดูว่าแต่ละค่ามาจากฟิลด์ไหนครบทุกค่าได้ที่ตาราง "ค่าแต่ละค่ามาจากฟิลด์ไหน" ด้านล่าง

0 · นิยามพื้นฐาน

  • ยอดเต็ม = ช่อง "เบี้ย + VAT + Duty" ของคนนั้น — นับต่อคน
  • ฐานลด = จุดตั้งต้นคิดส่วนลดต่อคน → ประเภท "Fix Amount" หรือ % + ฐาน "Exclude VAT" = เบี้ยเท่านั้น · % + "Include VAT" = ยอดเต็ม
  • ฐานรวม = ฐานลดของทุกคนรวมกัน — เช็ค "Min Purchase" และคิด % จากค่านี้เสมอ

1 · เช็ค Min Purchase

ถ้า ฐานรวม < ช่อง "Min Purchase" → ส่วนลดทั้งหมด = 0 (ยังต้องจ่าย VAT/Duty ตามปกติ)
ที่มา: ฐานรวม + ช่อง Min Purchase → ที่ไป: ตัดสินว่าคำนวณส่วนลดต่อหรือไม่

2 · ส่วนลดรวมหลัง Min/Max

Fix Amount: ส่วนลดรวม = MIN(ช่อง "ส่วนลดรวมทั้งรายการ", เบี้ยรวมทุกคน) — ลดได้ไม่เกินเบี้ย ไม่กัด VAT/Duty
Percentage: ดิบ = ฐานรวม × ช่อง "ส่วนลดรวมทั้งรายการ" ÷ 100 → ส่วนลดรวม = MIN(ดิบ, ช่อง "Max Discount")
(จำกัดด้วย Max เฉพาะ % — Fix Amount ไม่ใช้ Max Discount)
ที่มา: ช่องส่วนลดรวม + Min Purchase + Max Discount + ฐานรวม → ที่ไป: แจกทั้งรายการ (ขั้น 4) และคิดสัดส่วน Insurer (ขั้น 3)

3 · Insurer ลดรวม

Subsidize = Insurer → Insurer ลดรวม = ส่วนลดรวมทั้งหมด (ประกันรับหมด)
Subsidize = TQM → Insurer ลดรวม = 0 (TQM รับหมด)
Subsidize = BOTH → Insurer ลดรวม = ส่วนลดรวม × (ส่วนดิบของช่อง "Insurer ลด" ÷ ส่วนดิบของช่อง "ส่วนลดรวม")
  "ส่วนดิบ" = คำนวณจากฐานรวม ก่อนหัก Max Discount
  ⇒ แม้ส่วนลดรวมโดน Max บีบ สัดส่วน Insurer : TQM ก็ยังคงเดิม
ที่มา: dropdown Subsidize + ช่อง Insurer ลด + ส่วนลดรวม + ฐานรวม → ที่ไป: แบ่งต่อคน (ขั้น 4) และ TQM รับชำระจริง (ขั้น 6)

4 · แบ่งส่วนต่อคน

สัดส่วนของคนหนึ่ง = ฐานลดคนนั้น ÷ ฐานรวม
คนที่ 1: ลดรวม = ปัด 2 ตำแหน่ง (ส่วนลดรวม × สัดส่วน) · Insurer ลด = ปัด 2 ตำแหน่ง (Insurer ลดรวม × สัดส่วน)
คนที่ 2: ได้ "ส่วนต่าง" ที่เหลือ — รวมกันเป๊ะ ไม่มีเศษหายจากการปัด
TQM ลด = ลดรวม − Insurer ลด · จ่ายสุทธิ = ยอดเต็ม − ลดรวม
ที่มา: ส่วนลดรวม + Insurer ลดรวม + ฐานลดรายคน → ที่ไป: ตารางผลรายคน + ผลรวม (ขั้น 5)

5 · ผลรวมทุกคน

เบี้ยรวม · VAT รวม · Duty รวม · เบี้ย+VAT+Duty · TQM ลดรวม · Insurer ลดรวม · ส่วนลดรวม — บวกจากทุกคนตรงๆ
ที่มา: ผลรายคนจากขั้น 4 → ที่ไป: แถว "รวม" ของตาราง + ตาราง Front Office

6 · TQM รับชำระจริง (Sale Order) ⚠️ เข้าใจผิดบ่อยสุด

TQM รับจริง (ต่อคนและรวม) = ยอดเต็ม − Insurer ลด
ไม่หักส่วนลด TQM! เพราะ TQM อุดหนุนลูกค้าจากส่วนแบ่งของตัวเอง เงินที่ลูกค้าโอนเข้ามาจึงยังเต็ม — เอาไว้ทำ Sale Order
ที่มา: ยอดเต็ม + Insurer ลดรายคน → ที่ไป: ยอดรับจริงของ TQM (ต่างจากลูกค้าจ่ายสุทธิ)

7 · ลูกค้าจ่ายสุทธิรวม

ลูกค้าจ่ายสุทธิรวม = รวม (ยอดเต็ม − ลดรวม) ของทุกคน = ยอดเต็ม − ส่วนลดทั้งสองฝ่าย
ที่มา: จ่ายสุทธิรายคน → ที่ไป: ราคาที่แสดงลูกค้า (UI)

ตัวอย่างเต็ม — เคส 22 (BOTH ชน Max Discount)

อินพุต: ประเภท Percentage 20 · Insurer ลด 5 · Subsidize BOTH · 2 คน · ฐาน Exclude VAT · คน 1: เบี้ย 220 + VAT 0 + Duty 20 · คน 2: เบี้ย 340 + VAT 0 + Duty 20 · Min Purchase 200 · Max Discount 50
ขั้น 0: ยอดเต็ม 240 / 360 · ฐานลด 220 / 340 (Exclude → เบี้ยเท่านั้น) · ฐานรวม = 560
ขั้น 1: 560 ≥ Min 200 ✓ คำนวณต่อ
ขั้น 2: ดิบ = 560 × 20% = 112 → ส่วนลดรวม = MIN(112, Max 50) = 50
ขั้น 3: ส่วนดิบของส่วนลดรวม = 112 · ส่วนดิบของ Insurer ลด = 560 × 5% = 28 → Insurer ลดรวม = 50 × 28 ÷ 112 = 12.50 ⇒ Insurer 12.50 / TQM 37.50
ขั้น 4: คน 1: ลดรวม = ปัด(50 × 220/560) = 19.64 · Insurer ลด = ปัด(12.5 × 220/560) = 4.91 · TQM ลด = 14.73 · จ่ายสุทธิ 240 − 19.64 = 220.36
  คน 2: ลดรวม = 50 − 19.64 = 30.36 · Insurer ลด = 12.5 − 4.91 = 7.59 · TQM ลด = 22.77 · จ่ายสุทธิ 360 − 30.36 = 329.64
ขั้น 5: ส่วนลดรวม 50 · Insurer ลดรวม 12.50 · TQM ลดรวม 37.50
ขั้น 6: TQM รับชำระจริง = (240 − 4.91) + (360 − 7.59) = 587.50
ขั้น 7: ลูกค้าจ่ายสุทธิ = 220.36 + 329.64 = 550.00

ค่าแต่ละค่ามาจากฟิลด์ไหน — สรุปที่มาทุกค่าในหน้านี้

ข้อควรระวัง

  • Fix Amount ลดได้ไม่เกินเบี้ยรวม — VAT/Duty ยังต้องจ่ายครบ (และบังคับฐาน Exclude VAT, ไม่ใช้ Max Discount)
  • ส่วนลด % กรอก 20 หมายถึง 20% (ไม่ใช่ 0.20) และห้ามเกิน 100
  • Insurer ลด ใช้หน่วยเดียวกับประเภทส่วนลด: Fix = บาท / % = ตัวเลขเปอร์เซ็นต์ และห้ามเกินส่วนลดรวม
  • Max Discount เป็นเงินบาท ไม่ใช่เปอร์เซ็นต์
  • คนที่ 2 ได้เงินจาก "ส่วนต่าง" หลังปัดคนที่ 1 → ผลรวมตรงเป๊ะไม่มีเศษหาย
  • ส่วนลดติดลบไม่ได้ · PRB Add-on ไม่ร่วมลด
